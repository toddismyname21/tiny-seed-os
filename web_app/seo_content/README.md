## Deployment Instructions

### For Shopify:

1. **Create Pages:**
   - Go to Online Store > Pages > Add page
   - Switch to HTML mode (click `<>` button)
   - Paste content from HTML files
   - Set URL handle to match recommended URLs

2. **Schema Markup:**
   - The schema markup is already embedded in each page
   - No additional steps needed - Shopify preserves script tags

3. **Navigation:**
   - Add "CSA Guide" or "Learn About CSA" to main navigation
   - Link to pillar content page

### For Custom Web App:

1. Copy files directly to web server
2. Configure routing for clean URLs
3. Ensure proper content-type headers (text/html)

### For Headless CMS:

1. Extract content from `<article>` tags
2. Preserve schema markup in page head
3. Apply styling via your CSS system

## SEO Best Practices Implemented

1. **Schema Markup:**
   - LocalBusiness (farm details)
   - Article (content pieces)
   - FAQPage (every page has FAQ)
   - Product (CSA memberships)
   - AggregateRating (testimonials)

2. **On-Page SEO:**
   - Title tags under 60 characters
   - Meta descriptions under 160 characters
   - H1/H2/H3 hierarchy
   - Target keywords in headings
   - Internal linking opportunities
   - Image alt text placeholders

3. **Featured Snippet Optimization:**
   - Q&A format for FAQs
   - Clear answer paragraphs
   - Lists and tables
   - Numeric data (pricing, timing)

4. **Competitor Strategy:**
   - Never names competitors
   - "Aggregator platforms" as category
   - Positions on value, not attacks
   - Harvie relationship protected
