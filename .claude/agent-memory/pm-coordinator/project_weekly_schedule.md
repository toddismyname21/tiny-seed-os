## Pick/Pack List Generation Days
- **Monday** — pick lists for: Tuesday wholesale, Tuesday Lawrenceville Market, Wednesday CSA
- **Thursday** — pick lists for: Friday wholesale, Saturday Bloomfield Market, Saturday Sewickley Market, Sunday South Side Market, Weekend CSA

## Key Rules
- Floral pick lists are ALWAYS separate from vegetable pick lists
- Pick lists combine ALL outlets (CSA + wholesale + market) into one consolidated field harvest list
- Pack lists are separated by outlet/order after harvest comes into the packhouse
- Packer signs off on each order
