**2026 CSA share offerings (Todd-confirmed 2026-06-16). Use these exact labels — NOT the legacy DB `share_size` values like "family/regular/light," which are stale/mixed.**

| Share | Sizes | Frequency |
|---|---|---|
| **Summer Veg Share** | **large** or **small** | weekly or biweekly |
| **Flower Share** | **petite** or **full** | weekly or biweekly — **starts week of June 24** |
| **Farm Flex** | n/a — member chooses their own $ amount | pay-as-you-go (no set frequency) |

**Invoicing a mid-season signup:**
- **Summer veg:** subtract the weeks already passed (season started ~June 1) → member pays only for remaining weeks. This is **proration, NOT a perk.**
- **Flex:** no week-subtraction — member picks their own amount.
- **Flower:** starts week of June 24, so no missed weeks.

**No host perk.** CSA stop hosts do **not** get a discount/comp share. The "minus weeks" is purely proration for summer signups, not a host benefit. (Correcting an earlier wrong assumption.)

**Why:** Setting up host/member signups (e.g., Laurie Bittel, Cranberry host, 2026-06-16). **How to apply:** when drafting signup emails or building invoices, offer exactly these size/frequency options; payments run through Shopify (see [[csa-flex-store-credit]]).
