**`docs/CSA_GLOSSARY_OF_TRUTH.md` is THE single source of truth for every term, label, and rule** in the CSA/farm operation (created 2026-06-19 after Todd flagged that inconsistent labeling — same thing named differently each time — was causing gaps/holes and made him "fly blind" on CSA day).

**RULE: consult it before naming or labeling ANYTHING customer- or admin-facing, and never invent a synonym.** If a needed term isn't in it, ADD it to the glossary first, then use it everywhere consistently.

The non-negotiable labels it locks (the recurring drift traps):
- Sizes: Summer = **large/small** (NOT family/regular/light); Flower = **petite/full**.
- Weeks: **"Week of Jun 22 – Jun 28"** date range — NEVER "this/last/next week"; Week A/B = every-other-week from the Jun-8 anchor (NEVER "1st/3rd Wed").
- The week = **Mon–Sun, 4 pickup days** (Tue/Wed/Sat/Sun), holds through Sunday, rolls Monday.
- Order windows: swaps lock Mon 6AM (Tue/Wed)/Thu 6AM (Sat/Sun); flex à-la-carte Tue 6AM/Thu 6AM; opens Thursday.
- Money: Flex balance = **Shopify Store Credit** (source of truth); flex_transactions = audit ledger; **debit at order**.
- Catalog: **product_library** = master archive; everything links via library_id.

When the glossary changes, update both it AND the relevant project memories ([[week-on-the-farm]], [[csa-weekly-cycle]], [[csa-share-structure-2026]], [[box-swap-design]], [[flex-portal-state]]) so they never disagree.
