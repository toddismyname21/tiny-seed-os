# Computer Claude Registration Instructions

Send each Claude session the appropriate instructions file from this folder.

## How to Use

1. Open a Claude Code session on your computer
2. Copy/paste the relevant instructions file to that Claude
3. The Claude will register itself in the system

## Files in This Folder

| File | Send To |
|------|---------|
| `BACKEND_CLAUDE.md` | Backend Claude session |
| `UX_DESIGN_CLAUDE.md` | UX Design Claude session |
| `FIELD_OPS_CLAUDE.md` | Field Operations Claude session |
| `FINANCIAL_CLAUDE.md` | Financial Claude session |
| `SALES_CRM_CLAUDE.md` | Sales/CRM Claude session |
| `INVENTORY_CLAUDE.md` | Inventory/Traceability Claude session |
| `GRANTS_CLAUDE.md` | Grants/Funding Claude session |
| `EMAIL_COS_CLAUDE.md` | Email Chief of Staff Claude session |

## What Registration Does

Each Claude will:
1. Read the CLAUDE.md rules
2. Check the SYSTEM_MANIFEST.md for existing work
3. Update their session's OUTBOX.md with status
4. Be ready to receive assignments
