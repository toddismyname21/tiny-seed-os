Connect to Claude Code

Access Claude Code CLI remotely through the TinyPM bridge. Run commands, chat with Claude, and manage your projects from anywhere.

Setup Instructions

  1. Start the bridge server:
    python remote_terminal_bridge.py start
  2. Generate an access token:
    python remote_terminal_bridge.py token new
  3. For remote access, use ngrok:
    ngrok tcp 8765
  4. Enter the bridge URL and token above
