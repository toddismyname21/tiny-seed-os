## Executive Summary

After researching 8 leading social media management tools, clear industry patterns emerge for post composer design:

### Key Findings

1. **Two-Panel Layout is Industry Standard**: Left panel for editing, right panel for preview
2. **Intelligence is Collapsible**: Post ideas/suggestions can be hidden to maximize composer space
3. **Calendar Integration is Essential**: All tools offer calendar views (weekly/monthly) with drag-and-drop
4. **AI Assistance is Expected**: AI caption generation, hashtag suggestions, and best-time recommendations are now baseline features
5. **Mobile-First is Critical**: Most tools have robust mobile apps with full composer functionality
6. **Platform Customization per Post**: Ability to customize caption/media for each platform in a single workflow

## Tool-by-Tool Analysis

### 1. Later (later.com)

**Positioning:** Visual-first Instagram planning

#### A. Post Composer Layout
- **Text Input Position:** Center of composer with media preview above
- **Clicks to Composer:** 2-3 clicks from dashboard (select profile > create post)
- **Screen Ratio:** ~60% composer, ~40% grid preview/intelligence

#### B. Intelligence/Context Display
- **Hashtag Suggestions:** Provided during scheduling workflow
- **Optimal Posting Times:** Displayed as recommendations based on unique audience engagement data
- **Content Recommendations:** N/A (focus is on visual grid planning)
- **Intelligence Positioning:** Suggestions appear inline during scheduling, not stacked above

#### C. Multi-Platform Handling
- **Platform Handling:** Schedule same post for multiple platforms, customize per channel
- **Tabs/Toggles:** Channel selection via profile avatars at top
- **Character Limits:** Not prominently displayed in search results

#### D. Media Handling
- **Media Upload:** Drag-and-drop to calendar or dedicated upload area
- **Inline Editing:** Built-in editing tools for on-the-fly adjustments
- **Carousel Support:** Full support for Instagram carousels (up to 10 slides)
- **Live Preview:** Visual Planner shows grid preview of how feed will look

#### E. Scheduling UX
- **Post Now vs Schedule:** Both options available, schedule is emphasized
- **Calendar Integration:** Toggle between monthly, weekly, and list views
- **Bulk Scheduling:** Drag-and-drop multiple items from media library

#### F. Mobile Considerations
- **Approach:** Strong mobile app with Quick Schedule feature
- **Mobile Features:** Visual Instagram Planner (Preview) available on iOS/Android, sync across devices

#### G. Killer Feature
- **What Makes it GREAT:** Visual Instagram Planner - drag-and-drop grid preview showing exactly how your feed will look
- **Pattern to Steal:** Grid preview with drag-and-drop reordering for visual-first planning

### 2. Buffer (buffer.com)

**Positioning:** Simplicity and ease of use

#### A. Post Composer Layout
- **Text Input Position:** Central text box with "Start writing or Use the AI Assistant" placeholder
- **Clicks to Composer:** 1 click (global + New button in top navigation)
- **Screen Ratio:** ~70% composer, ~30% scheduling/intelligence sidebar

#### B. Intelligence/Context Display
- **Hashtag Suggestions:** Free hashtag generator tool; hashtag manager for saving groups
- **Optimal Posting Times:** Recommendations based on engagement patterns and recent performance (plan-dependent)
- **AI Assistant:** Available to all users - "rephrase, shorten, expand, make more casual or formal"
- **Intelligence Positioning:** AI assistant inline in composer; analytics in separate tab

#### C. Multi-Platform Handling
- **Platform Handling:** Select channels via avatars at top; selected channels appear in color
- **Channel Groups:** Create groups to select multiple channels at once
- **Customization:** Click within boxes for each channel to customize per platform
- **Character Limits:** Platform-specific customization available

#### D. Media Handling
- **Media Upload:** Copy/paste or drag-and-drop images directly into composer
- **Image Reordering:** Drag-and-drop to reorder images in posts
- **Carousel Support:** Supported with image reordering
- **Alt Text:** Edit image to crop or add alt-text descriptions

#### E. Scheduling UX
- **Scheduling Options:** Left side of composer offers:
  - Next Available (add to next posting slot)
  - Prioritize (top of queue)
  - Set Date and Time (custom)
  - Now (immediate publish)
- **Calendar Integration:** Visual calendar with queue system
- **Post Duplication:** One-click duplicate for reusing top performers

#### F. Mobile Considerations
- **Approach:** Full-featured mobile app with intuitive design
- **Mobile Composer:** Green + icon (iOS) or pencil icon (Android) opens composer
- **Mobile Calendar:** Calendar view with day view across all channels
- **Recent Updates:** Fresh design with Apple's Liquid Glass system, Apple Watch app

#### G. Killer Feature
- **What Makes it GREAT:** One-click global composer access from anywhere in the app
- **Pattern to Steal:** Global "+ New" button in persistent top navigation; channel avatars that color when selected

### 3. Hootsuite (hootsuite.com)

**Positioning:** Enterprise-grade features

#### A. Post Composer Layout
- **Text Input Position:** Central "Your Post" section after selecting social accounts
- **Publish To Menu:** Social account selection above content area
- **Screen Ratio:** ~50% composer, ~50% preview and scheduling options

#### B. Intelligence/Context Display
- **Hashtag Generator:** Built-in, auto-generates hashtags
- **Best Time to Post:** Heat maps showing when followers are most active; recommended times in calendar
- **AI Caption Writer:** Auto-generates captions
- **Trend Discovery:** Search by topic, company, hashtag to find trending content
- **Intelligence Positioning:** Right-hand corner preview; scheduling suggestions in calendar window

#### C. Multi-Platform Handling
- **Platform Handling:** "Publish To" menu for account selection
- **Per-Network Preview:** Real-time preview updates as you compose
- **Network-Specific Tabs:** Facebook and LinkedIn have dedicated tabs for audience targeting
- **Character Limits:** Twitter preview shows when you exceed limits

#### D. Media Handling
- **Media Upload:** Computer, cloud services, or built-in media library
- **Design Tools:** Access Canva and Adobe Express templates directly in Composer
- **Video Support:** Create MP4s using Adobe Express, import directly
- **Stock Media:** Royalty-free images and GIFs included
- **Alt Text:** Supported for Twitter, Facebook, LinkedIn images
- **Video Captions:** SRT caption file support for Facebook and Twitter videos

#### E. Scheduling UX
- **Action Options:** Bottom-right section offers "Save As Draft," "Schedule For Later," or "Post Now"
- **Calendar Integration:** Planner tab with grid or list view; drag-and-drop rescheduling
- **Bulk Composer:** Schedule up to 350 posts at once via CSV upload
- **Crisis Management:** Easily suspend scheduled posts for unexpected situations

#### F. Mobile Considerations
- **Mobile Composer:** Compose button in bottom menu
- **Mobile Uploads:** Direct photo, video, GIF uploads from phone
- **Platform Support:** Instagram (carousels), TikTok, Facebook, LinkedIn, Twitter
- **Planner on Mobile:** Review drafts, content calendar at a glance, approve content anywhere

#### G. Killer Feature
- **What Makes it GREAT:** Bulk Composer (350 posts at once) + built-in Canva/Adobe Express integration
- **Pattern to Steal:** Real-time per-network preview; integrated design tools (Canva, Adobe) in composer

### 4. Sprout Social (sproutsocial.com)

**Positioning:** B2B focused, enterprise collaboration

#### A. Post Composer Layout
- **Layout:** Two-panel design - edit screen on LEFT, preview on RIGHT
- **Merged Areas:** Text and media areas merged for streamlined experience (Sept 2024 update)
- **Screen Ratio:** ~50% editor, ~50% preview (fullscreen mode)
- **Profile Picker:** Searchable by network name or profile name

#### B. Intelligence/Context Display
- **Optimal Send Times:** Star ratings showing best times based on 16 weeks of audience data
- **ViralPost Technology:** Algorithm-driven optimal times, up to 60% lift in reach
- **AI Assist:** Generative AI copywriting support directly in Compose Window
- **Intelligence Positioning:** Optimal times displayed at point of scheduling

#### C. Multi-Platform Handling
- **Platform Handling:** Profile Picker to select multiple profiles
- **Customization Limitation:** General caption and media apply to all selected profiles (no per-network customization in same view)
- **Instagram-Specific:** First comment, SproutLink, collaborators (up to 3)

#### D. Media Handling
- **Media Sources:** Computer, Asset Library, Bynder, Canva, Dropbox, Google Drive
- **Video Editor:** Crop, trim, choose templates, select video ratios per network, add stickers
- **Carousel Support:** Supported with direct scheduling

#### E. Scheduling UX
- **Scheduling Options:** "Specific day and time" selector; schedule up to 13 months in advance
- **Multiple Time Slots:** Schedule a post at multiple time slots
- **Bulk Scheduling:** Create/plan up to 350 messages via CSV upload
- **Approval Workflow:** Built-in with edit, reschedule, team conversation, reject, approve actions

#### F. Mobile Considerations
- **Mobile Compose:** Full compose functionality on desktop and mobile
- **Task Management:** Create, route, manage Tasks from mobile
- **Push Notifications:** Alerts when messages need approval
- **Asset Library:** Available on mobile

#### G. Killer Feature
- **What Makes it GREAT:** ViralPost optimal send times with 60% reach improvement; enterprise approval workflows
- **Pattern to Steal:** Star-rating system for optimal times; merged text/media area for cleaner interface

### 5. Planoly (planoly.com)

**Positioning:** Visual-first, Instagram-centric

#### A. Post Composer Layout
- **Text Input Position:** Below media preview area
- **Grid-Centric:** Automatically pulls 18 most recent Instagram posts for visual planning
- **Screen Ratio:** ~70% visual grid/preview, ~30% editing controls

#### B. Intelligence/Context Display
- **AI Caption Writer:** Multiple voice options to match brand style
- **Hashtag Manager:** Save hashtags in organized groups; counter shows remaining (max 30 for Instagram)
- **Intelligence Positioning:** Hashtag groups accessible during caption writing

#### C. Multi-Platform Handling
- **Platforms:** Instagram, TikTok, YouTube, Facebook, X, Pinterest, LinkedIn, Amazon, Threads
- **Cross-Platform:** Plan across all platforms simultaneously
- **Auto-Posting:** Supported for all connected platforms

#### D. Media Handling
- **Upload Sources:** Phone, computer, Dropbox, Google Drive
- **Video Editor:** Cut, combine clips, add filters (mobile app)
- **Content Templates:** Professionally designed, customizable layouts
- **Splitter Tool:** Free tool to split single photo into multiple Instagram posts

#### E. Scheduling UX
- **View Options:** List, gallery, and grid view; customizable calendar colors
- **Placeholders:** Set recurring placeholders for content strategy visualization
- **Preview Feature:** Eye icon shows post preview before publishing (checks for text cutoff)

#### F. Mobile Considerations
- **Approach:** Mobile-first design - "plan content anytime, anywhere"
- **Mobile App:** Full planning, scheduling, publishing from iOS/Android
- **Advanced Video Editor:** Mobile-only feature for editing videos

#### G. Killer Feature
- **What Makes it GREAT:** Visual grid planner that shows exactly how your Instagram feed will look
- **Pattern to Steal:** Drag-and-drop grid aesthetic; preview icon to check how posts will render with social icons

### 6. Tailwind (tailwindapp.com)

**Positioning:** Pinterest and Instagram specialist

#### A. Post Composer Layout
- **Entry Points:** Browser extension for on-page pinning OR drag-and-drop visual uploader
- **Calendar View:** Weekly or monthly view with drag-and-drop
- **Screen Ratio:** ~60% content creation, ~40% calendar/schedule

#### B. Intelligence/Context Display
- **SmartSchedule:** Analyzes unique audience to recommend best posting times
- **Hashtag Finder:** Color-coded recommendations (niche, good, best, competitive)
- **Counter:** Automatic hashtag count (alerts at 30)
- **Intelligence Positioning:** Hashtag suggestions pop up as you type caption

#### C. Multi-Platform Handling
- **Platforms:** Pinterest, Instagram, Facebook
- **Multi-Network Scheduler:** Cross-post to all platforms simultaneously
- **Browser Extension:** Schedule directly from any webpage

#### D. Media Handling
- **Pin Creation:** Browser extension auto-pulls page title, URL, and images
- **Batch Upload:** Upload multiple designs at once
- **Instagram Grid Preview:** Drag-and-drop 9-grid preview

#### E. Scheduling UX
- **SmartSchedule:** Personalized schedule based on audience activity
- **Calendar Interface:** Drag-and-drop; plan weeks/months in advance
- **First Comment:** Auto-post hashtags to first comment instead of caption

#### F. Mobile Considerations
- **Mobile App:** Full feature parity - drag-drop calendar, grid preview, hashtag finder
- **Sync:** Desktop and mobile apps synced
- **Stories:** Schedule Instagram stories from mobile

#### G. Killer Feature
- **What Makes it GREAT:** SmartSchedule that actually learns YOUR specific audience; color-coded hashtag recommendations
- **Pattern to Steal:** Color-coded hashtag competitiveness (niche/good/best/competitive); inline hashtag suggestions as you type

### 7. Loomly (loomly.com)

**Positioning:** Content calendar and collaboration focus

#### A. Post Composer Layout
- **Condensed Design:** Two panels (down from original six steps)
- **Generic Panel:** Basic content setup, post ideas, visual assets, platform selection
- **Fine-Tuning Panel:** Per-channel customization (overrides generic)
- **Screen Ratio:** ~60% editor panels, ~40% preview

#### B. Intelligence/Context Display
- **Post Ideas (5 Types):**
  1. X/Twitter Trends (location-based)
  2. RSS feeds (custom selection)
  3. Loomly Inspirations (best practices)
  4. Loomly Ideas (events, holidays, celebrations)
  5. Custom Post Ideas (user-defined recurring/one-off)
- **Collapsible Post Ideas:** Toggle visibility with "Show/Hide" - clean interface by default
- **Hashtag Suggestions:** Relevant hashtags during composition
- **Intelligence Positioning:** Post Ideas collapsible in Generic Panel; date/time always visible in footer

#### C. Multi-Platform Handling
- **Two-Panel System:** Generic Panel for all platforms; Fine-Tuning Panel for per-channel customization
- **Per-Channel Overrides:** Different scheduled times, captions, media per channel
- **Post Labels:** Tag posts for campaign/category filtering

#### D. Media Handling
- **Sources:** Canva integration, Unsplash, Google Drive
- **Loomly Studio:** Crop, resize images/videos per platform aspect ratio (Instagram squares, Facebook Reels)
- **Alt Text:** Supported on images
- **Cover Images:** Add thumbnails to videos

#### E. Scheduling UX
- **Calendar Features:** Drag-and-drop posts; scheduling slots to speed up posting
- **View Options:** Calendar view or List view; filter by date, format, channel, media, status, assignee
- **Quick Posts:** Create directly from calendar cell
- **Approval Workflows:** Built-in collaboration and approval system

#### F. Mobile Considerations
- **Mobile Post Builder:** Full composer on iOS/Android
- **Mobile Library:** Upload visual assets on the go
- **Push Notifications:** Alerts when posts require action
- **Feature Parity:** Post ideas, generic + fine-tuning, post optimization all available

#### G. Killer Feature
- **What Makes it GREAT:** Collapsible Post Ideas with 5 different inspiration sources; two-panel Generic/Fine-Tuning system
- **Pattern to Steal:** Collapsible inspiration panel that doesn't interrupt workflow; "Custom Post Ideas" for brand-specific recurring content

### 8. SocialBee (socialbee.com)

**Positioning:** Category-based posting and evergreen recycling

#### A. Post Composer Layout
- **Two-Panel Design:** Post editor on LEFT, previews on RIGHT
- **Text Editor Features:** Hashtags, bold, italic, strikethrough, emojis, character count
- **Screen Ratio:** ~50% editor, ~50% preview panel

#### B. Intelligence/Context Display
- **AI Post Generator:** Generate captions and images
- **Best Time Recommendations:** Based on past post performance
- **Category System:** Organize content by type (educational, promotions, announcements, memes)
- **Intelligence Positioning:** AI generator accessible in editor; analytics inform scheduling

#### C. Multi-Platform Handling
- **Profile Selection:** Select multiple profiles from editor
- **Customization Options:**
  - "Customize for each profile" (manual)
  - "Customize each caption" (AI-powered)
- **Single Draft to Multiple Platforms:** Core value proposition

#### D. Media Handling
- **Integrations:** Canva, Unsplash, GIPHY directly in editor
- **Live Preview:** Adjust, crop, flip, rotate until perfect
- **Carousel Support:** Up to 10 photos/videos; crop to right size with preview

#### E. Scheduling UX
- **Category-Based Queuing:** Each category has own posting slots; system auto-picks next post
- **Category Sequence:** Define posting order across categories (e.g., 1st Friday = Curated, 2nd = Promotional)
- **Evergreen Recycling:** "Requeue" option republishes content indefinitely
- **Expiration:** Set posts to expire after publishing or on specific date
- **Generate Schedule:** Auto-create schedule based on best practices per platform

#### F. Mobile Considerations
- **Mobile App:** Full content creation, scheduling, analytics
- **RSS Feed:** Connect blogs directly
- **Evergreen on Mobile:** Recycle content from anywhere

#### G. Killer Feature
- **What Makes it GREAT:** Category-based scheduling with evergreen recycling - fill calendar for months/years
- **Pattern to Steal:** Content categories with automatic queue rotation; "Generate Schedule as per best practices" button

## Recommended UX Patterns to Adopt

### High Priority (Adopt Immediately)

#### 1. Two-Panel Layout
```
+------------------+------------------+
|                  |                  |
|   POST EDITOR    |   LIVE PREVIEW   |
|   (Left 50%)     |   (Right 50%)    |
|                  |                  |
+------------------+------------------+
```
**Source:** Sprout Social, SocialBee, Loomly

#### 2. Global Composer Access
- Persistent "+ Create" button in top navigation
- 1-click access from anywhere in app
- **Source:** Buffer

#### 3. Channel Selection with Visual Avatars
- Profile avatars at top of composer
- Color change when selected (grayed out = unselected)
- Channel groups for quick multi-select
- **Source:** Buffer, Hootsuite

#### 4. Collapsible Intelligence Panel
- Post ideas/suggestions hidden by default
- "Show/Hide" toggle to expand
- Doesn't interrupt composition flow
- **Source:** Loomly

#### 5. Inline AI Assistant
- "Start writing or use AI" placeholder text
- Rephrase, shorten, expand options
- Generate hashtags on demand
- **Source:** Buffer, Sprout Social, SocialBee

### Medium Priority (Phase 2)

#### 6. Optimal Posting Times Display
- Star ratings or heat maps
- Personalized to specific audience
- Displayed at scheduling step
- **Source:** Sprout Social (ViralPost), Hootsuite, Tailwind (SmartSchedule)

#### 7. Color-Coded Hashtag Suggestions
- Niche (blue) / Good (green) / Best (gold) / Competitive (red)
- Counter showing remaining allowed hashtags
- Auto-post to first comment option
- **Source:** Tailwind

#### 8. Per-Platform Customization Flow
- Generic panel for base content
- Fine-tuning tabs for per-channel overrides
- Character limit indicators per platform
- **Source:** Loomly, Buffer

#### 9. Visual Grid Preview (Instagram)
- 9-grid preview showing feed aesthetic
- Drag-and-drop reordering
- **Source:** Later, Planoly, Tailwind

### Lower Priority (Future Enhancement)

#### 10. Category-Based Scheduling
- Organize posts by content type
- Automatic queue rotation
- Evergreen content recycling
- **Source:** SocialBee

#### 11. Bulk Composer
- CSV upload for mass scheduling
- Up to 350 posts at once
- **Source:** Hootsuite, Sprout Social

#### 12. Built-in Design Tools
- Canva/Adobe Express integration
- Stock photo library (Unsplash)
- GIF library (GIPHY)
- **Source:** Hootsuite, Loomly, SocialBee

### Key Interaction Patterns

1. **Profile Selection:** Tap avatars to toggle (animated color change)
2. **Media Upload:** Drag-drop on desktop, tap area on mobile
3. **AI Assistant:** Click "AI" button or type "/" for commands
4. **Intelligence Panel:** Collapsed by default, expand via chevron
5. **Preview Tabs:** Click platform tabs to see each preview
6. **Scheduling:** Bottom bar always visible; calendar popup for date selection
7. **Best Times:** Displayed as subtle hint below scheduling bar
