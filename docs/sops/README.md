## The weekly rhythm, as the SOPs state it

| | |
|---|---|
| **Order cutoffs** | CSA Wed-run **Mon 7 AM** · Weekend (Sat/Sun) **Thu 7 AM** · Wholesale Wed **Tue 7 AM** · Wholesale Fri **Thu 7 AM** |
| **Harvest** | **Mon** (for the Wed run) · **Thu** (for the weekend run) |
| **Pack & deliver** | Tue = Lawrenceville market · **Wed = CSA delivery** · Sat = Bloomfield + Sewickley · Sun = South Side *(Sat + Sun are one "weekend run," packed together)* |

Crew coverage (from `CHANGE_LOG` 2026-07: pack-house handoff build): **pack crew works
Mon / Tue / Thu; the FIELD crew takes over Friday** for the weekend markets. That
Tue → Thu gap plus the Thu → Fri crew change is why the handoff feature exists.
