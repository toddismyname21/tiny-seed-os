# SEO Dashboard - User Guide

## Quick Start

The SEO Dashboard helps you track and improve your search rankings for Tiny Seed Farm. Access it at: `web_app/seo_dashboard.html`

---

## What This Dashboard Does

1. **Track Keyword Rankings** - Monitor where you rank for important search terms
2. **Log & Track Reviews** - Keep track of Google, Yelp, and Facebook reviews
3. **Manage Citations** - Track business directory listings (Local SEO)
4. **Get AI Insights** - Wizard AI provides actionable recommendations
5. **Automate Rank Checking** - Optional SerpAPI integration for daily tracking

---

## How to Use

### 1. Log Rankings (Manual)
If you don't have SerpAPI set up:
1. Click **"Log Rankings"** button
2. Open Google in incognito mode
3. Search each keyword (e.g., "CSA pittsburgh")
4. Count what position Tiny Seed Farm appears
5. Enter the number in the form
6. Click **"Save Rankings"**

Do this weekly for best tracking.

### 2. Auto-Check Rankings (Requires SerpAPI)
If you have SerpAPI configured:
1. Click **"Auto-Check"** button
2. Wait for the check to complete
3. Rankings are automatically logged

### 3. Log Reviews
When you receive a new Google/Yelp/Facebook review:
1. Click **"Log Review"** button
2. Select the platform
3. Enter reviewer name
4. Select star rating
5. Paste the review text
6. Click **"Save Review"**

### 4. Log Citations
When you list your business on a new directory:
1. Click **"Add"** next to Citation Status
2. Select the directory from the dropdown
3. Select status (Submitted, Live, Pending)
4. Enter the listing URL
5. Click **"Save Citation"**

### 5. Use Action Guides
Click any insight or action item to see step-by-step instructions:
- Each guide explains what to do
- Includes time estimates
- Links to relevant tools (Google Business Profile, etc.)

## Setting Up Automation (Optional)

### SerpAPI Integration
For automated daily rank checking:

1. Sign up at [serpapi.com](https://serpapi.com) (~$50/month for 5000 searches)
2. Copy your API key
3. In the SEO Dashboard, click **"Settings"**
4. Paste your SerpAPI key
5. Enter your alert phone number (for rank drop alerts)
6. Set alert threshold (default: 3 position drop)
7. Click **"Enable Daily 7AM Check"**
8. Click **"Save Settings"**

The system will now:
- Check rankings automatically at 7 AM daily
- Send SMS alerts if rankings drop significantly
- Log all results to your tracking sheet

## Troubleshooting

### "Failed to load rankings"
- Check your internet connection
- Verify the API is deployed and working
- Try clicking "Refresh"

### "SerpAPI: Not configured"
- Click the "Initialize" button in the API status bar
- Or go to Settings and enter your SerpAPI key

### Rankings not updating
- Make sure to click "Save Rankings" after entering values
- Check that values are numbers between 1-100
- If using auto-check, verify SerpAPI is configured

### Reviews showing 0
- Log your first review to start tracking
- The dashboard tracks reviews you manually log
- It does not automatically pull from Google/Yelp

## SEO Best Practices

1. **Weekly Ranking Checks** - Track rankings every week to spot trends
2. **Respond to Reviews** - Reply to all reviews within 24 hours
3. **Complete Citations** - NAP (Name, Address, Phone) must be identical everywhere
4. **Post to GBP** - Post to Google Business Profile 2-3 times per week
5. **Get Reviews** - Target 2-3 new reviews per week
6. **Content is Key** - Blog posts with target keywords help rankings
