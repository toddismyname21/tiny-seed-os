## ⭐ 1. Why this one matters more than it looks

**AIG Round 1 approved a $24,000 PTO compost turner. It has never been spent.
It expires 2027-06-30.**

| | |
|---|---|
| **AIG** buys | the machine that turns the compost |
| **AMP 317** buys | the pad and bays the machine needs to work on |

**Two grants, two halves of one system, no overlap.** And a compost turner
without a hard surface to work on is a machine looking for a job.

## 2. What it is

A dedicated area for making compost — contained, on an impervious surface, so
leachate does not run off and the pile can be managed and turned properly.

## 3. What we physically do

| | |
|---|---|
| Pour a **concrete pad**, sized to the turner's width | the turner dictates bay width |
| Build **bays** — concrete or wood walls | typically 3 bays: active, turning, finished |
| Manage | load, turn on schedule, monitor temperature, cure |
| Spread | which feeds **336 Soil Carbon Amendment** at $321/ac |

**Where:** near the barn, on ground that is already compacted and not in
production. ⚠️ **Must not disturb crop ground** and must satisfy the CPA-52
review — concrete is a permanent change and will get looked at.

## 4. 🔴 What we record

| Record | When |
|---|---|
| **Compost plan** — feedstocks, C:N target, turning schedule | before building |
| **Temperature log** — ⭐ required for organic certification anyway (131–170°F, 15 days, 5 turns for the NOP process) | each batch |
| Feedstock log — what went in, when, how much | each batch |
| Turning log | each turn |
| **Finished compost analysis** | each batch |
| Spreading records — block, rate, date | feeds 590 and 336 |

⭐ **The NOP already requires most of this.** Organic certification and this
practice want the same records.

## 5. 🔴 The leased-land problem

**Concrete is permanent.** On leased ground it is an improvement to someone
else's property, and if the lease ends you cannot take it with you.

➡️ **This needs Don Kretschmann's written agreement before it is proposed**, and
it is worth asking whether a **non-permanent surface** — heavy geotextile and
compacted stone — qualifies for a reduced version of the practice.
