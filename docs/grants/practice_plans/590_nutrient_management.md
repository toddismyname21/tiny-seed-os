## 1. What it is

Applying nutrients in the right amount, source, placement and timing — from soil
test data, to a written plan, with records proving you followed it and adjusted.

## 2. What we physically do

**The testing already happens — Logan Labs.** What is missing is the plan
wrapped around it.

| Step | What happens |
|---|---|
| **Sample** | soil test by block, same blocks each year so the trend means something |
| **Plan** | write what goes on each block, how much, when, and why — from the test |
| **Apply** | compost, OMRI-approved amendments, per the plan |
| **Re-test** | same blocks, next season |
| **Adjust** | change the plan where the numbers moved differently than expected |

**Where:** across the production blocks in **FSA Fields 1 and 2.**

## 3. What we buy

Soil tests. Already a line in the farm budget — **this practice pays for the
analysis and planning around tests that are already being purchased.**

## 4. 🔴 What we record

| Record | When |
|---|---|
| **Soil test results by block** | annually, same blocks |
| **Written nutrient plan** — per block, per crop: material, rate, timing, justification from the test | **before the season** |
| Application log — date, block, material, rate, method | each application |
| **Compost analysis** — if you spread your own, test it so rates are real | each batch |
| ⭐ **ADJUSTMENT** — *"phosphorus climbed in the JS blocks, so compost there was cut and nitrogen came from cover crop instead"* | annually |

## 5. Practical notes

⭐ **This is the cheapest practice on the whole list to qualify for**, because the
expensive input — soil testing — is already being bought.

⭐ **It stacks with 336 Soil Carbon Amendment and 340 Cover Crop.** The nutrient

It is also the thing an inspector will ask about.
