# WHY THESE TWO

## 1. They are two of only four cropland acres FSA recognises

The cropland indicator is set on exactly four fields across the whole 97-acre
operation:

| Farm / Tract / Field | Acres | Type | Cropland |
|---|---|---|---|
| ⭐ **1068 / 446 / 1** | **33.55** | **HEL** | **YES** |
| ⭐ **1068 / 446 / 2** | **1.24** | **HEL** | **YES** |
| 1079 / 1583 / 1 | 3.76 | HEL | YES |
| 1238 / 1783 / 1 | 5.50 | HEL | YES |

**Picking a non-cropland field would invite a question nobody wants asked.**

## 2. Same farm, same tract — the simplest possible administration

Both commodities on **one farm, one tract.** One conservation plan, one set of
records, one practice. Pasa's rules want a specific field per commodity; giving
them two adjacent fields on the same tract is the cleanest version of that.

## 3. Both are Highly Erodible Land — and that is an advantage

Erosion is the **documented, USDA-recognised resource concern** on this ground,
so **Mulching 484 needs no justification.** A conservation practice on HEL is not
an improvement someone has to argue for — it is what the land is classified as
requiring. HEL ground is also typically weighted favourably in ranking.

## 4. The sizes fit what each crop actually needs

| | |
|---|---|
| **Field 1, 33.55 ac → salad greens** | Todd said salad will be **in many fields**. Field 1 is the largest piece of cropland on the operation and can hold many production blocks |
| **Field 2, 1.24 ac → tomatoes** | ⭐ Todd's tomato blocks are **F3L (0.51 ac) + F3M (0.28 ac) = 0.79 ac**. That **fits inside 1.24 acres with room to spare.** The tomato planting does not need 33 acres and should not claim them |

## 5. The acreage reported is production acreage, not field acreage

Established when the field map was reconciled: **the FSA field number is an
address.** If tarps go on 2 acres of greens sitting inside field 1, the
application reports **2 acres of practice on 1068/446/1** — not 33.55. Nobody is
on the hook for treating the whole tract.
